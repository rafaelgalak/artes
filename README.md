# Banco de artes

Galeria dos carrosséis da HEYCHAMP e do @_rafaelgalak: **https://rafaelgalak.github.io/artes**

## Como subir um carrossel
1. Crie uma pasta `AAAA-MM-DD_nome` com as imagens numeradas na ordem (`01_capa.jpg`, `02_...`).
2. No GitHub: entre em `heychamp/` ou `pessoal/` → **Add file → Upload files** → arraste a pasta inteira → **Commit**.
3. Em ~1 minuto a ação "Atualizar galeria" roda e o carrossel aparece no site.

Opcional: um `info.json` na pasta com `titulo`, `status` (`rascunho`, `pronto`, `postado`) e `legenda`.
